# Земля у моря — Щёлкино

Посадочная страница ООО «Точка притяжения» для продажи земельных участков Восточного Крыма.

**Текущий режим:** GitHub Pages — прототип для проверки, с `noindex`; платная реклама пока ведёт на старый нейролендинг. Не переключать её на GitHub Pages.

- Щёлкино / район Бухты Космонавтов: участки от 4 соток; 1-я линия 2 млн ₽, 2-я 1,5 млн ₽, 3-я 1,2 млн ₽.
- В том же районе крупные: 90:07:200601:1587 (~49 соток), 90:07:200601:1621 (~33 сотки). Участок 90:07:200601:2273 (~2,4 га) — проект туристического комплекса рядом, а **не продажа**.
- СНТ Керчи: отдельный блок с «Коммунальником», «Горняком» и «Вишенкой», ориентир цены от 700 тыс. ₽.
- «Скиф» — отдельный посёлок, ориентир от 500 тыс. ₽.
- Телефон: +7 978 296-41-08.

## Код и визуал

- `index.html` — главная страница, блок цен, карта, галерея, 3D-тур «Азгард», отдельные направления и форма;
- `assets/style.css` — стили и адаптивная вёрстка, системные шрифты (без внешнего Google Fonts);
- `assets/main.js` — галерея, ленивый 3D-тур, перенос UTM в iframe Яндекс Форм;
- `assets/img/plot-*.svg` — трассированные **схематические** контуры по присланным снимкам, не юридические границы; старые `map-*-hq.jpg` оставлены для проверки;
- `politika.html` — политика обработки персональных данных, требует финальной юридической сверки;
- Яндекс Форма: `https://forms.yandex.ru/u/6adc777e852af3c4d5fc9a8f/` (аккаунт azgardcrimea); тест полного получения заявки пока не подтверждён.
