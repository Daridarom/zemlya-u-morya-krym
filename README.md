# Земля у моря — Щёлкино

Посадочная страница для продажи участков в Восточном Крыму (ООО «Точка притяжения»).
Фокус — участки у Азовского моря в Щёлкино; ниже — 30–50 соток, посёлок «Скиф», СНТ в Керчи.

## Статус

Прототип на GitHub Pages для просмотра и правок. Реклама сюда не ведёт, страница закрыта от поисковиков (`noindex`).

## Перед переездом на рабочий домен

- Подтвердить цены 4 соток по линиям и телефон.
- Форма: подключить обработчик на российском хостинге (телефоны клиентов хранятся в России, 152-ФЗ) и прописать адрес в `FORM_ENDPOINT` в `assets/main.js`.
- Политика обработки персональных данных — отдельная страница, ссылка у галочки согласия.
- Перенести фото с серверов Яндекса в `assets/img/` (сейчас подключены по ссылкам с текущего лендинга).
- Убрать плашку «Прототип» и `noindex`, подключить Яндекс Метрику и цели (заявка, звонок, MAX, Telegram).

## Структура

- `index.html` — страница
- `assets/style.css` — оформление
- `assets/main.js` — форма заявки и нижняя кнопка на телефоне
- `assets/img/` — фрагменты кадастровых карт из обзора участков
