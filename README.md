# Земля у моря — Щёлкино

Посадочная страница ООО «Точка притяжения» для предложений по земельным участкам в Восточном Крыму.

**Статус:** опубликованный прототип на GitHub Pages для проверки дизайна (`noindex`, без рекламы). Рабочий домен и российский хостинг готовятся отдельно; действующие объявления Директа не изменяются до проверки.

- **Щёлкино, участки от 4 соток у Азовского моря:** первая линия 2 000 000 ₽, вторая 1 500 000 ₽, третья 1 200 000 ₽.

- **Посёлок «Скиф»:** от 500 000 ₽, подбор по расположению и коммуникациям.
