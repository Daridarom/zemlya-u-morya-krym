1. **Кадастровые визуализации.** Вместо мутных изображений 560 px добавлены масштабируемые векторные схемы `plot-1587.svg`, `plot-1621.svg`, `plot-2273.svg`. Ссылки на исходные `map-*-hq.jpg` сохранены.
2. **Мобильная вёрстка.** Уменьшен рост фотографического первого экрана; улучшены переносы заголовков и размеры кнопок. Проверка на живых телефонах остаётся необходимой.
3. **Скорость/приватность.** Снята зависимость от CDN Google Fonts. Системный стек шрифтов не делает лишних запросов в зарубежный сервис.
4. **Точность предложений.** Удалена неподтверждённая фраза о рыночных ценах других объявлений. Разделы строго раздельны: 4 сотки у Бухты Космонавтов (2 / 1,5 / 1,2 млн ₽), крупные участки в том же районе, СНТ Керчи, отдельно «Скиф».
5. **Юридическая прозрачность.** Под схемами явное ограничение: приблизительная форма, точные границы и площадь проверяются по ЕГРН. Участок :2273 — развиваемый туристический проект, а не продаваемая позиция.

1. Получить подтверждённое имя домена и доступ к российскому размещению.
2. Проверить компанию-оператора, адрес и политику; при необходимости обновить `politika.html`.

4. Собрать `dist` по инструкции `DEPLOYMENT.md`; хостинг в РФ, HTTPS, независимый хост для нового сайта, минимальные технические проверки.

6. После проверки скорректировать рекламные ссылки в подходящих группах Директа, дождаться модерации и сверить факт показа/целевой URL. Не менять бюджет, ставки и статус строительной группы.
7. Записать изменения, скриншоты и read-back в основной TASK. Держать план возврата старой ссылки.

### Проверка кода и опубликованного сайта

- После пересборки публикация на GitHub Pages показана браузером Opera, первый экран и блок контактов просмотрены. Удалён iframe Яндекс Формы. Прямая форма по известному адресу доступна (заголовок «Заявка — участки Щёлкино»).
- Статические инварианты: все целевые `#якоря` ведут к существующим идентификаторам, повторов ID нет, 10 разделов, карточки с утверждёнными ценами и номерами на месте. В `main.js` есть обработчики открытия/закрытия изображений, 3D-тура, мобильного меню и проброса параметров UTM/yclid.
- Доступные исходные webp/svg файлы остались в репозитории. Публичный сайт сохраняет `noindex` и плашку «Предварительная версия».
- Ограничение тестов: инструмент просмотра не предоставляет эмуляцию мобильной ширины и клики по кнопкам. Фактический сценарий ввода телефона/доставки ответа, вращение 3D в Safari, работа из российских мобильных сетей и полнота Метрики здесь **не проверены**.

### Риски, которые не исправляются одной вёрсткой

1. **Форма действительно короче только на сайте, не у оператора.** Действующая Яндекс Форма продолжает запрашивать интерес, телефон, способ связи и согласие. Для дальнейшего сокращения нужно редактировать саму форму у владельца аккаунта `azgardcrimea`, не ломая обязательное согласие и интеграцию уведомлений.
2. **Выбранный вариант не передаётся в поле формы автоматически.** У Яндекс Форм есть механизм предзаполнения, но для него нужны точные ID вопроса и ответа. Этого соответствия пока нет. Не заменять рекламную UTM-метку непроверенным значением для имитации предзаполнения. См. https://yandex.ru/support/forms/ru/pre-fill
3. **Переход во внешнюю форму меняет домен.** Для корректной аналитики нужно обеспечить прослеживаемость кампании и факта отправки именно у Яндекс Форм, а затем сверять с полученными ответами. Метка `utm_*` теперь передаётся в ссылке; одна только эта операция не доказывает конверсий.
4. **Политика формы пока ссылается на URL GitHub Pages.** Перед переводом на собственный домен нужно изменить ссылку в самой Яндекс Форме на актуальную политику рабочего сайта и согласовать формулировки с юристом.
5. **Нет проверенного рабочего домена/доступа к хостингу.** GitHub Pages нельзя объявлять российским размещением персональных данных. Сайт телефон сам не собирает, данные оставляются у Яндекс Форм; точные условия хранения и договорной роли проверить отдельно.
6. **Несоответствие запросов в Директе.** Объявления про СНТ и «Скиф» требуют релевантных страниц или по крайней мере переходов в соответствующие разделы, а не автоматически на первый экран про Щёлкино. До перевода трафика — сверить фактические ссылки, категории и объявления.
