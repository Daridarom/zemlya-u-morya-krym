## Сборка рабочей версии

При доступе к компьютеру с исходниками:

```bash
git clone https://github.com/Daridarom/zemlya-u-morya-krym.git
cd zemlya-u-morya-krym
python3 scripts/build-production.py --domain YOUR-DOMAIN.ru --form-verified --policy-reviewed
```

Ключи `--form-verified` и `--policy-reviewed` указывать только после фактического подтверждения этих условий.

Папка `dist/` содержит сайт под корнем выбранного домена. Загрузить **содержимое** `dist/` на российский хостинг. Не копировать в корень сайта файлы другого проекта; использовать отдельный сайт/каталог, сохранить старую версию для отката. Установить HTTPS-сертификат, проверить доступность `/`, `/politika.html`, `/assets/img/plot-1587.svg` и `robots.txt`.

## Обязательные проверки перед сменой URL

1. Подтвердить **конкретный домен**, принадлежность и доступ к российскому хостингу. Не использовать `alexblagov.ru` автоматически: это другой действующий проект.
2. Проверить юридические реквизиты ООО, адрес в политике, основания обработки, согласие в Яндекс Форме и фактическое размещение персональных данных.
3. С разрешения Алексея отправить **одну явно помеченную тестовую заявку** и проверить в Яндекс Формах/почте получение, согласие, источник и время. Не засчитывать тест в лиды.
4. Проверить мобильный сайт с российского подключения (320–430 px), навигацию, фото, 3D-тур, ссылки, статус HTTP 200 и HTTPS. Точное соответствие утверждённым ценам и кадастровым номерам.
5. Настроить новый счётчик Яндекс Метрики для **нового домена** (или проверить согласованное использование существующего); целевое действие — **подтверждённая отправка**, а не нажатие кнопки. Проверить, какие события может предоставить Яндекс Форма и где действительно собираются данные.
6. После успешного контроля обновлять URL **только подходящих земельных объявлений**, соблюдать принадлежность Скифа/СНТ к своим группам, дождаться модерации. Не возобновлять остановленную строительную группу самовольно; бюджет/ставки не менять.
7. Сделать скриншоты и технический read-back и записать действие в TASK кампании.
8. План отката: восстановить прежний рекламный URL и старую версию сайта в случае ошибок формы/сайта.

## Известные UX-риски и улучшения

- Первый экран телефона содержит много текста: заголовок, цену и CTA проверять целиком на 320–390 px; избегать белого пустого экрана при загрузке изображений.
- Нельзя смешивать три ценовые линии у моря, большие участки, СНТ в Керчи и «Скиф».
- Панорама «Азгарда» — **ориентир по соседнему проекту**, не демонстрация точных границ продаваемого участка.
- Кадастровые схемы **иллюстративные**, геометрию подтвердить выписками ЕГРН до точных юридических заявлений.
- Вместо неподтверждённого «рыночного сравнения» показывать проверенную цену и способ получить актуальные варианты.
- Убрать зависимость от внешнего Google Fonts до рабочего запуска; текущая версия использует системные шрифты.
